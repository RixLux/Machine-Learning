## Manajemen file jupiter notebook aka .ipynb

### 1. Install tool-nya (bisa lewat pip atau conda)
```
pip install nbstripout
```

### 2. Daftarkan tool ini ke dalam konfigurasi Git di repo aktif
```
nbstripout --install
```

> Ini akan otomatis menghapus output dari notebook saat melakukan commit dengan tetap mempertahankan file asli di lokal komputer.
